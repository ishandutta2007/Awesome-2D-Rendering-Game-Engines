This repository tracks notable **commercial / hosted platforms** and **open-source projects** for **2D Rendering & Game Engines**. ## Sector Overview & Market Dynamics

The global game engine and real-time development software market is estimated at approximately **$3.6B to $4.4B** (scaling past $38B+ when factoring broader simulation and enterprise visual tech). The market structure exhibits a dual dynamic: it is **heavily concentrated at the top**—dominated by an oligopoly (Unity and Epic Games) capturing massive industry revenue and game volume—while remaining **moderately fragmented across the mid and lower tiers**, where a vibrant ecosystem of specialized 2D tools, web/HTML5 runtimes, and community-driven open-source alternatives thrive.

## Open-Source GitHub Projects

- **[PixiJS](https://github.com/pixijs/pixijs)**  

  The HTML5 Creation Engine—high-performance 2D WebGL renderer used as the foundation for many web games and interactive experiences (including Phaser).



- **[Phaser](https://github.com/phaserjs/phaser)**  

  Popular open-source HTML5 2D game framework built on PixiJS, offering scenes, physics, input, animation, and a large plugin ecosystem for browser games.



- **[Godot Engine](https://github.com/godotengine/godot)**  

  Fully open-source multi-platform engine with excellent 2D tools, scene system, GDScript, animation, tilemaps, and one of the strongest free 2D workflows available.



- **[Defold](https://github.com/defold/defold)**  

  Open-source 2D-focused game engine from King, designed for high performance on mobile and web, with a Lua scripting model and data-driven architecture.



- **[Love2D](https://github.com/love2d/love)**  

  Lightweight, flexible 2D framework using Lua, beloved for its simplicity and direct control over rendering and game logic.



- **[MonoGame](https://github.com/MonoGame/MonoGame)**  

  Open-source reimplementation of Microsoft’s XNA framework, enabling C# 2D (and 3D) game development across desktop, mobile, and consoles.



- **[LibGDX](https://github.com/libgdx/libgdx)**  

  Battle-tested open-source Java framework for cross-platform 2D and 3D games with a strong community and extensive tooling.



- **[Heaps.io](https://github.com/HeapsIO/heaps)**  

  High-performance open-source graphics engine (Haxe) used for 2D and 3D games, powering several commercial titles.



- **[HaxeFlixel](https://github.com/HaxeFlixel/flixel)**  

  Open-source 2D game framework built on Haxe and OpenFL, offering a Flash-like API for cross-platform 2D development.



- **[Raylib](https://github.com/raysan5/raylib)**  

  Simple and easy-to-use open-source library for learning and making games in C, with strong 2D support and bindings for many languages.



### Additional Strong Open-Source Options

- Using **PixiJS** as a pure high-performance 2D renderer for custom engines or interactive web content.

- Building complete games with **Phaser** for browser targets or **Godot** for multi-platform desktop/mobile.

- Choosing **Defold** or **Love2D** when a lightweight, scriptable 2D-focused engine is preferred.

- Leveraging **MonoGame** or **LibGDX** for C# / Java teams targeting multiple platforms.

- Combining open engines with free asset pipelines and community plugins for indie and educational projects.

- Accepting that commercial tools (Construct 3, GameMaker, Unity 2D, RPG Maker, Cocos Creator) still lead in visual editors, asset stores, one-click publishing, and beginner-friendly workflows.



**Frameworks for building custom systems**: Start with **PixiJS** or **Phaser** for web → use **Godot** or **Defold** for native multi-platform 2D → fall back to **Love2D**, **MonoGame**, or **LibGDX** for language-specific preferences. Suitable for indie developers, educators, and teams that want full source control. Many commercial productions still choose Unity, GameMaker, or Construct for tooling speed and ecosystem support.
